# Making the next episode (how episode 1 "alavandar" was made)

Case folder: crime/<case>/ with script.txt, scenes.json, plan.json, youtube.json.
1. script.txt: sections `## 01 hook` ... `## 10 ending` (see crime/alavandar/script.txt). Spoken colloquial Tamil, 6-8 min, ~800-900 words. Hook -> disclaimer -> background -> investigation -> clues -> "what would you do?" question -> answer -> arrest -> court verdict -> ending with the question for comments and a teaser of the next case. Only court-decided cases; facts checked on the web; no real names of living private persons beyond what the court record says.
2. scenes.json: {"shots":[{"n":1,"scene":"..."} ... ~60-65 (medium: one new picture about every 7 seconds; the daily neuron limit allows ~95 klein pictures)]}: comic pictures drawn by Cloudflare FLUX.2 klein 4B (16:9, 1280x720, ~105 neurons a picture; daily free limit 10,000 neurons per account, resets 5:30 AM IST; MODEL=schnell gives old squares). Wording rules: no "blood", no years/numbers (they turn into printed text), write "clean floor"; object-only still lifes for sensitive moments; never real photos.
3. plan.json: {"bgm_volume":0.07,"pictures":[{"sec":"01","cue":null,"n":1},...],"tags":[{"sec","cue","text","style":"tag|big|card","delay","for"}],"episode":{"num":N,"title":"THE ... CASE","sub":"CITY | YEAR"}}. Cue = a phrase of the section text where the picture/tag starts.
4. Workflows (Actions, input case=<case>): Crime Story Full Voice -> Crime Story Pictures -> Crime Story Build Video (puts the video on branch video-<case>) -> Crime Video Upload (private). Voice is Gemini Charon, plain; crime/tts_clean.py removes Gemini's end-of-clip noise burst.
5. youtube.json: title "EP N | <hook> | Solved Crime Files - Tamil", description with chapters (times: hook, intro at the end of the hook, then each section start + 13 s for the intro), tags, pinned_comment. Thumbnail: 1280x720 jpg from crime/thumb_layouts.py (board, circle or split; never reuse either of the last 2 layouts, see crime/thumb_layouts.json). Saved as assets/crime_<case>_thumb.jpg. Pass THUMB path via the upload workflow env if different.
The video is uploaded PRIVATE; the owner makes it Public himself and pins the comment. Do not set the AI-generated/altered-content flag.

## Standing rules added 2026-11-15
- Thumbnail: a different layout each time (crime/thumb_layouts.py), subtle controversy wording tied to the story, modern (sans) Tamil lettering. Avoid the Tamil words/forms that the font draws badly (e.g. "கொள்ளை", "சிக்கினார்": use "திருட்டு", "கைது").
- Subtitles on YouTube as closed captions in Tamil and English (not burned in): write crime/<case>/subs_en.txt (same `## NN name` headers as the script, one English line per caption; `python crime/subs.py <case> <voice-dir> --list` prints the numbered Tamil captions), then `python crime/subs.py <case> <voice-dir>` writes subs_ta.srt and subs_en.srt (timed from the voice durations plus the 13 s intro). crime/upload.py uploads both tracks automatically; for an already uploaded video run the "Crime Video Captions" workflow. The channel key needs the youtube.force-ssl permission.
- Show the finished video and thumbnail to the owner and upload only after he approves.

## Standing rule added 2026-11-21: multi-part cases link all their parts
Whenever a part of a multi-part case is uploaded (Part 2, Part 3 ...), add its video id to crime/series.json (series key = the case, parts in order) and run the "Crime Series Links" workflow: every part's description then starts with one line linking all parts (replaces older single-part link lines). Do this right after the upload, without asking.

## Like / Subscribe buttons (added 2026-11-21)
Every episode's plan.json gets "buttons": one mid-video where the narrator first asks for a comment/guess, one at the closing line ("உங்க கருத்தைக்..."), e.g. {"sec":"06","cue":"உங்க யூகத்தைக்"}, {"sec":"10","cue":"உங்க கருத்தைக்"}. build.py lays assets/crime_subscribe.mov (made by crime/subbtn.py) bottom-left.
